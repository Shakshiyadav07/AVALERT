🚨 AVALERT — Avalanche & Disaster Rescue Intelligence Platform
Rapid Intelligence. Precision Rescue. Saving Lives When Every Second Counts.

📌 Executive Summary
AVALERT is a next-generation AI-powered Disaster Management & Emergency Response Platform. Designed specifically for critical scenarios like avalanches, severe landslides, and flash floods, AVALERT bridges the gap between stranded citizens, field rescue teams, and relief coordinators through real-time telemetry, spatial intelligence, and automated SOS routing.

🏗️ System Architecture & Tech Stack

Frontend & UI Engine
Core Framework: React.js powered by Vite (Lightning-fast build & HMR)
Styling & Motion: Tailwind CSS v4 + Framer Motion (Fluid, responsive, accessible UI)
State Management: React Context API (AppContext.jsx)
Vector Graphics: Custom High-DPI SVG Icon System
